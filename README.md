# Vatsal Chandrani — Portfolio

> An interactive, IDE-style portfolio,

> Explore at: [vatsal-chandrani.me](https://vatsal-chandrani.me)

## About

This isn't a traditional portfolio website. It's a **fully interactive VS Code-inspired code editor** where visitors can:

- Browse my profile as source files (`About.cpp`, `Skills.js`, `Projects.md`, `Experience.java`...)
- Run a **working terminal** with real commands (`g++ about.cpp -o about`, `./about`, `help`)
- Explore projects as **installable extensions** in an Arsenal panel
- View my journey as a **visual commit timeline** in Chronicles
- Navigate everything with **keyboard shortcuts** just like a real IDE

## Features

- **File Explorer** — Open files from the sidebar to view syntax-highlighted content

- **Working Terminal** — Compile and execute commands with realistic output

- **Arsenal · My Toolkit** — Projects, future ideas and business ideas displayed as VS Code-style extension cards with detail pages

- **Chronicles · My Journey** — Career timeline of my life

- **Keyboard Shortcuts** — `Ctrl + `` ` toggle terminal,
        `Ctrl +Shift +E/X/G` switch panels

- **Interactive Onboarding Tour** — First-time visitor guide with progress tracking

- **Draggable Panels** — Resize sidebar and terminal like a real IDE
